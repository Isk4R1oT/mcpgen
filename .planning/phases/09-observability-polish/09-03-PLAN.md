<!-- Org-scope helper (extract from drift.ts:48-62 per RESEARCH §"Don't Hand-Roll") -->
```ts
async function deploymentBelongsToOrg(deploymentId: string, orgId: string): Promise<boolean> {
  const r = await db.execute(sql`
    SELECT p.org_id AS org_id
    FROM deployments d
    JOIN generations g ON g.id = d.generation_id
    JOIN projects p ON p.id = g.project_id
    WHERE d.id = ${deploymentId}
    LIMIT 1
  `);
  const rows = r.rows as unknown as { org_id: string }[];
  return rows[0]?.org_id === orgId;
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9-bff-auth-01 | Spoofing | Logto JWT replay | mitigate | `authMiddleware` already verifies issuer + audience + expiry (Phase 8) — D-18 routes inherit |
| T-9-bff-auth-02 | Information Disclosure | Foreign-org deployment access via predictable ID | mitigate | `deploymentBelongsToOrg` 4-table JOIN; 404 not 403 (defense-in-depth) per PATTERNS.md key finding #2 |
| T-9-bff-auth-03 | Elevation of Privilege | M2M token used to mutate org data | mitigate | Explicit `auth.isM2M` check returns 403 `m2m_cannot_*` |
| T-9-bff-auth-04 | Tampering | SQL injection via deployment ID parameter | mitigate | Drizzle parameterized SQL (`${deploymentId}` is sql.identifier param, not string concat); zValidator on body |
| T-9-bff-auth-05 | Information Disclosure | Listing all deployments without org scope | mitigate | `WHERE p.org_id = ${auth.organizationId}` is mandatory in the SQL; test 2 of deployments-list verifies cross-org isolation |
