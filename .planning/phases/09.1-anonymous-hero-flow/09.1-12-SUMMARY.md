### Task 1 — Cross-phase input doc (commit `7c92510`)

`.planning/phases/09.1-anonymous-hero-flow/09.1-PRIVACY-INPUT.md` (142 lines, ~7 KB) with these sections:

| Section | What it provides Phase 10-09 |
|---------|------------------------------|
| **Background** | Two unauthenticated-data surfaces (IP rate limit + anon session cookie) — frames why disclosure is needed |
| **What we collect** | Anon: IP-hash, ULID cookie, generation metadata. Signed-in: Logto-managed profile (with link to Logto privacy policy) |
| **Why we collect it** | Article 6(1)(f) legitimate interest for IP-hash; strictly-necessary basis for the session cookie; explicit "no tracking/analytics/ads on unauthenticated traffic" |
| **How we minimize** | Raw IP NEVER stored; daily-rotating salt with ≤48h re-identification window; opaque-ULID cookie with no third-party scope |
| **Retention table** | 7 categories: raw IP (never) / salt history (2d) / hash log (30d) / anon-linkage (7d) / ephemeral deploy (24h) / cookie (7d) / generation artifacts (indefinite, no PII) — each with reason cited |
| **User rights** | Article 17 erasure via privacy@mcpgen.app — manual procedure (provide IP → we recompute hash → delete matching rows from current retention window). Self-serve interface noted as roadmap |
| **Cookies summary** | Single-row table for `mcpgen_anon_session` (HttpOnly, SameSite=Lax, Secure prod, 7d) — pairs with Phase 7 D-19 cookie disclosure |
| **GDPR citations** | 7-row reference table: Articles 4(5), 5(1)(c), 6(1)(f), 17, 33, 5(1)(b/e), Recital 26 |
| **Verbatim §11 quote** | Lead paragraph reproduced verbatim from RESEARCH §11 for traceability |
| **Implementation evidence** | Backlinks to migration `20260501010000_phase09_1_anon_flow.sql` + 7 specific Phase 9.1 plan files (04 schema, 05 hashing, 10 crons, etc.) so legal review can verify schema↔claim parity |
| **Plan 10-09 must do** | 5 explicit instructions (drop into privacy.md, add Last-updated, cross-link cookies, provision privacy@ inbox, cite both files in pre-publish checklist) |
| **Plan 10-09 must NOT do** | 5 explicit guardrails (no faster-than-30d promise, no "anonymized" misnomer within retention window, no Turnstile reference, no tracking cookies, no dropping the anon-session-cookie disclosure) |

The disclosure language is **drop-in ready** — Phase 10-09 can paste it
