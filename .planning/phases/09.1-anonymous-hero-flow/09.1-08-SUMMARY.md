## What Shipped

### `cf-platforms-deploy.ts` — 3 wrappers

**Single source of truth** for every caller that touches the CF Workers
for Platforms REST API in this phase:

| Function          | URL shape                                                                                          | Idempotency                              | Local-compute behavior              |
| ----------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------- | ----------------------------------- |
| `deployScript`    | `PUT  /accounts/{id}/workers/dispatch/namespaces/mcpgen-prod/scripts/{name}` (multipart)           | Idempotent on `(name, content, tags)`    | Returns `http://localhost:9000/{name}/mcp` |
| `deleteScript`    | `DELETE /.../scripts/{name}`                                                                       | 404 ⇒ success (cleanup-cron invariant)   | No-op                                |
| `retagScript`     | `PUT  /.../scripts/{name}/tags`  (JSON body)                                                       | Replaces tag set wholesale               | No-op                                |

**Pitfall #11 invariant:** the `NAMESPACE` constant is hard-coded to
`mcpgen-prod`. The pre-commit hook `no-fourth-namespace.sh` runs as a
secondary defense (see Deferred Issues #2 below for a known regex bug
that does NOT affect plan 08 since plan 08 introduces no 4th namespace).

### Tag format (verbatim per RESEARCH §8 lines 1000–1006)

```
["anon=true", "expires_at=2026-05-02T00:00:00.000Z", "session=01HX0123456789ABCDEFGHJKMN"]
```

Free-form `=`-separated key/value strings. The cleanup cron (plan
09.1-10) reads `tag.startsWith("expires_at=")` to find scripts past
their 24h window.

### `POST /api/v1/deploy/ephemeral` flow

```
client → anon cookie (mcpgen_anon_session)
       → POST { generation_id }
       → readAnonSession(c)            # 400 no_anon_session if missing
       → generationBelongsToAnonSession # 403 forbidden if foreign
       → deployScript({ scriptName: anon-{ulid().lowercase().slice(0,10)},
                       tags: [anon=true, expires_at=<ISO>, session=<cookie>] })
       → INSERT deployments (
           anon_session_id = $cookie,
           expires_at      = NOW() + 24h,
           dispatch_namespace = 'mcpgen-prod',
           ...
         )
       → 202 { deployment_id, url, expires_at }
```

The route returns `https://{scriptName}.mcpgen.app/mcp` in production
and `http://localhost:9000/{scriptName}/mcp` under local-compute. The
cleanup-by-tag query (RESEARCH §3 lines 326–335) picks up the row via
`expires_at IS NOT NULL AND anon_session_id IS NOT NULL`.

   the verify condition still passes; the latent guard breakage
