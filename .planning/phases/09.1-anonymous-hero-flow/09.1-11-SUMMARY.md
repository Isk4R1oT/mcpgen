## Local-stack run command

The full suite expects:

1. BFF on `:8787`, web on `:3000`, engine on `:8000` via `pnpm dev` at the repo root (`MCPGEN_LOCAL_COMPUTE=1` from plan 08).
2. Postgres + Inngest dev server reachable per phase 09.1-04 migration.
3. (Optional, for ANON-04 claim assertion) `E2E_FAKE_JWT` set in `apps/api/.dev.vars` as a fixture-mode local Logto JWT.

Run:

```bash
RUN_E2E=1 MCPGEN_LOCAL_COMPUTE=1 MCPGEN_FRONTEND_MODE=live \
  pnpm --filter @mcpgen/web test:e2e \
    tests/e2e/anon-flow.spec.ts \
    tests/e2e/anon-rate-limit.spec.ts \
    tests/e2e/anon-claim-fixation.spec.ts
```

Without the env vars the entire suite is `test.skip`-ped at describe level — `pnpm --filter @mcpgen/web test:e2e --list` still lists all 7 tests so CI test discovery sees them.

## RUN_E2E gating + nightly schedule recommendation

| Trigger | RUN_E2E | When | Cost (approx) |
| - | - | - | - |
| Per-PR CI run | unset | every push | $0 (suite skipped) |
| Pre-merge gate | `RUN_E2E=1` | pre-merge into main | engine + BFF roundtrip × 7 tests; <8 min wall-clock with cache hits |
| Nightly | `RUN_E2E=1` | 03:00 UTC cron | full suite × all branches with open PRs |
| Manual local | `RUN_E2E=1` | developer-driven | as-needed |

The `RUN_E2E=1` gate addresses threat T-9.1-11-01 (E2E suite slow → CI minutes burn) — the gate is the kill-switch that keeps per-PR run cost at $0 while preserving the nightly + pre-merge regression surface.

## Decisions Made

See frontmatter `key-decisions` for the 5 substantive decisions. Summary:

1. **Signup simulation: approach (c)** (direct POST + E2E_FAKE_JWT) over (a) real Logto and (b) cookie injection. Cleanest CI signal; isolates claim contract from OAuth flake.
2. **BFF-direct calls in rate-limit tests 1+2** — middleware contract regression surfaces without webserver in the path.
3. **Cache-hit graceful degradation** — annotation-skip on cold cache rather than fail; preserves TDD framing.
4. **ATTACKER_FAKE_ULID format-valid by design** — forces the cold-start rotation gate to fire on Referer heuristic alone, not as a side effect of malformed-cookie short-circuit.
5. **No middleware-redirect E2E coverage** — already pinned by 9 vitest cases in `tests/middleware-route-gate.test.ts`. E2E's job is the full chain (cookie → cache → claim) that vitest cannot reach.
