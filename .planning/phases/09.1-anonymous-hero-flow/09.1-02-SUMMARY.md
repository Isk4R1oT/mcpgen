# Phase 9.1 Plan 02: Per-route Auth Refactor + BFF_ANONYMOUS_GATE Summary

## One-liner

Replaced Phase 8's blanket `app.use('/api/v1/*', authMiddleware)` with per-route Hono sub-app mounting controlled by the `BFF_ANONYMOUS_GATE` env var; the original 401-on-anon-`POST /api/v1/generate` bug is closed at the auth-boundary level without touching JWT verification logic.

## What changed

### `index.ts` before/after structure

**Before (Phase 8 blanket gate):**

```ts
const app = new Hono();
// Public layers 1+2+3
app.get('/health', ...);
app.route('/_spike/sse', ...);
app.route('/api/v1/stripe/webhook', stripeWebhookRoute);  // public-by-signature
app.on(['GET','PUT','POST'], '/api/inngest', ...);
// Layer 4: /internal/v1/* — M2M sub-app
const internalApp = new Hono(); internalApp.use('*', authMiddleware); internalApp.use('*', requireM2M);
app.route('/internal/v1', internalApp);
// Layer 5: BLANKET gate over the entire user-facing /api/v1/*
const protectedApp = new Hono(); protectedApp.use('*', authMiddleware);
protectedApp.route('/generate', generateRoute);   // ← anon was 401-blocked here
protectedApp.route('/jobs', jobsStreamRoute);     // ← anon was 401-blocked here
protectedApp.route('/billing/checkout', checkoutRoute);
protectedApp.route('/billing/portal', portalRoute);
protectedApp.route('/', driftRoute);              // self-prefixed
protectedApp.route('/', deploymentsRoute);
protectedApp.route('/', usageRoute);
protectedApp.route('/', deployRoute);
app.route('/api/v1', protectedApp);
export default app;
```

**After (Phase 9.1 plan 02 per-route + flex gate):**

```ts
export function buildApp(env: Bindings): Hono {
  const app = new Hono();
  // Layers 1+2+3 unchanged: /health, /_spike/sse, /api/v1/stripe/webhook, /api/inngest
  // Layer 4 unchanged: /internal/v1/* M2M sub-app
  const protectedApp = new Hono();
  protectedApp.use('*', authMiddleware);     // ← gotcha #1: BEFORE any route()
  // ALWAYS-PUBLIC /api/v1 routes (mounted on `app`, BEFORE protectedApp catch-all)
  app.route('/api/v1/generate', generateRoute);              // anon-allowed (D-08)
  app.route('/api/v1/jobs', jobsAnonRoute);                  // anon-allowed (cookie-scoped)
  app.route('/api/v1/deploy/ephemeral', ephemeralDeployRoute); // D-03
  // GATE-CONDITIONAL routes
  const gate = env.BFF_ANONYMOUS_GATE ?? 'playground';
  if (gate === 'deploy')   { app.route('/api/v1/preview', ...);  app.route('/api/v1/quality', ...);  app.route('/api/v1/playground', ...); }
  else if (gate === 'quality')  { app.route('/api/v1/preview', ...);  app.route('/api/v1/quality', ...);  protectedApp.route('/playground', ...); }
  else if (gate === 'preview')  { app.route('/api/v1/preview', ...);  protectedApp.route('/quality', ...); protectedApp.route('/playground', ...); }
  else /* 'playground' */       { protectedApp.route('/preview', ...); protectedApp.route('/quality', ...); protectedApp.route('/playground', ...); }
  // ALWAYS-PROTECTED routes
  protectedApp.route('/dashboard', dashboardRoutes);
  protectedApp.route('/billing', billingRoutes);
  protectedApp.route('/download', downloadRoute);
  protectedApp.route('/claim_generation', claimRoute);
  protectedApp.route('/', driftRoute);                        // self-prefixed (existing)
  protectedApp.route('/', deploymentsRoute);                  // self-prefixed (existing)
  protectedApp.route('/', usageRoute);                        // self-prefixed (existing)
  protectedApp.route('/', deployRoute);                       // self-prefixed (existing)
  app.route('/api/v1', protectedApp);                         // ← gotcha #2: LAST
  return app;
}
export default { fetch: (req, env, ctx?) => buildApp(env).fetch(req, env, ctx) };
```

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Default-export `fetch` signature widened to `Partial<Bindings>`**

- **Found during:** Task 2 typecheck — exporting `Bindings` made TS strict on the `default.fetch(req, env)` signature; existing tests pass partial env objects (only the bindings they exercise) and broke compilation in `tests/routes/drift.test.ts`, `usage-hourly.test.ts`, `deployments-list.test.ts`, `stripe-webhook.test.ts`, `contract.test.ts`, `auth-mounting.test.ts`.
- **Fix:** Default export `fetch` accepts `Partial<Bindings>` and casts to full `Bindings` at the boundary. CF Workers always passes the complete env at runtime; this only relaxes the type for tests. `buildApp(env)` itself still requires full `Bindings` so the test factory call is checked properly.
- **Files modified:** `apps/api/src/index.ts`
- **Commit:** a43bbae (folded into GREEN)

**2. [Rule 1 — Bug] `tests/auth-mounting.test.ts` asserted obsolete behavior**

- **Found during:** Task 2 verification.
- **Issue:** The test asserted `GET /api/v1/jobs/abc/stream` returns 401, which is the exact Phase 8 regression D-07 fixes. Leaving it would break the suite.
- **Fix:** Updated the test to assert the new behavior — `/jobs/:id/stream` is anon-allowed (non-401) and `/dashboard` is the canonical always-protected endpoint instead. Rewrote the docstring to reference the Phase 9.1 plan 02 layered structure.
- **Files modified:** `apps/api/tests/auth-mounting.test.ts`
- **Commit:** a43bbae (folded into GREEN)
